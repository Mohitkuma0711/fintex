# ADR 0003: Grounded answers and citations

- **Status:** Accepted
- **Decision:** Factual tax answers must be grounded in official-source content
  retrieved from the knowledge base and returned with citations.
- **Rationale:** Users need to verify the source and currency of guidance.
- **Consequences:** Knowledge documents need source metadata and update/version
  handling; unsupported factual answers must not be presented as sourced.
